Active Reconnaissance: SNMP Enumeration

Querying target SNMP agents using snmpwalk to extract system telemetry.

root@htb:~# snmpwalk -v2c -c public 10.129.14.128 
SNMPv2-MIB::sysDescr.0 = STRING: Linux target 5.15.0 #98-Ubuntu SMP
SNMPv2-MIB::sysObjectID.0 = OID: NET-SNMP-MIB::netSnmpAgentOIDs.10
SNMPv2-MIB::sysContact.0 = STRING: Admin <admin@target.htb>
SNMPv2-MIB::sysName.0 = STRING: enterprise-core-router
IF-MIB::ifDescr.1 = STRING: eth0
IF-MIB::ifDescr.2 = STRING: eth1 (Internal 10.10.10.0/24)
Recon Role: When running snmpwalk, your host acts as the SNMP Manager querying the target Agent.
RECON CHECKLIST High-Value Discovery OIDs
  • System Info: sysDescr → OS distribution & kernel version.
  • Admin Contacts: sysContact / sysName → Admin emails & hostnames.
  • Interfaces: ifDescr / ifPhysAddress → Maps internal NICs & subnets.
  • Processes & Software: hrSWRunName → Active daemons & packages.
  • Routing Tables: ipRouteDest → Internal network topology.
