Active Reconnaissance: SNMP Enumeration

Sistem telemetrisini elde etmek için snmpwalk kullanarak hedef SNMP agent'larını query etme.

root@htb:~# snmpwalk -v2c -c public 10.129.14.128 
SNMPv2-MIB::sysDescr.0 = STRING: Linux target 5.15.0 #98-Ubuntu SMP
SNMPv2-MIB::sysObjectID.0 = OID: NET-SNMP-MIB::netSnmpAgentOIDs.10
SNMPv2-MIB::sysContact.0 = STRING: Admin <admin@target.htb>
SNMPv2-MIB::sysName.0 = STRING: enterprise-core-router
IF-MIB::ifDescr.1 = STRING: eth0
IF-MIB::ifDescr.2 = STRING: eth1 (Internal 10.10.10.0/24)
Recon Rolü: snmpwalk çalıştırırken host'unuz, hedef Agent'ı query eden SNMP Manager olarak hareket eder.
RECON KONTROL LİSTESİ Yüksek Değerli Discovery OID'leri
  • Sistem Bilgisi: sysDescr → OS dağıtımı ve kernel versiyonu.
  • Admin Kontakları: sysContact / sysName → Admin e-postaları ve hostname'ler.
  • Interface'ler: ifDescr / ifPhysAddress → Dahili NIC'leri ve subnet'leri haritalandırır.
  • Süreçler & Yazılım: hrSWRunName → Aktif daemon'lar ve paketler.
  • Routing Tabloları: ipRouteDest → Dahili network topolojisi.
