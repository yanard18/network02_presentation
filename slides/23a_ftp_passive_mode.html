Passive FTP Mode

Client-initiated data stream designed for firewall evasion.

PASSIVE MODE Client → Server Connection
  • Mechanism: Client issues PASV; server assigns high-port for client-initiated data stream.
  • Firewall Evasion: Outbound client connection bypasses perimeter filters (reverse shell concept).
  • Modern Challenge: Zero-Trust internal segmentation increasingly filters high-port traffic.
Firewall Solution: Client initiates both Control & Data channels outbound.
