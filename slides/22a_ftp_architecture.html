FTP Control Connection

Persistent TCP control channel for command exchange and session management.

CONTROL STREAM TCP Port 21
  • Connection: Client opens TCP handshake to Port 21.
  • Command Exchange: Carries ASCII commands (USER, PASS, LIST).
  • Persistent Channel: Remains open throughout the entire FTP session.
  • Separation: Control and actual file data streams are completely decoupled.
