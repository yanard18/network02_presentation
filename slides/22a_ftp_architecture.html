FTP Control Connection

Komut değişimi ve oturum yönetimi sağlayan kalıcı TCP control channel.

CONTROL STREAM TCP Port 21
  • Bağlantı: Client, Port 21 üzerine TCP handshake başlatır.
  • Komut Alışverişi: ASCII komutlarını taşır (USER, PASS, LIST).
  • Kalıcı Kanal: Tüm FTP session boyunca açık kalır.
  • Kanal Ayrımı: Control ve gerçek dosya data stream yapıları birbirinden tamamen bağımsızdır.
