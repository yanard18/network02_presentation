Lightweight Transfer: TFTP Protocol

Connectionless, stripped-down file transfer for network device configuration and bootstrapping.

ARCHITECTURE TFTP vs. FTP
  • Purpose: Lightweight transfer for firmware, router configs, & PXE boot images.
  • Transport Protocol: Operates over UDP 69 (initial handshake) + dynamic UDP data ports.
  • Connectionless: No delivery guarantees or error control → faster but less reliable.
  • Security Risk: Inherently insecure — zero authentication or encryption capabilities.
root@htb:~# tftp 10.129.14.150 69 
tftp> status
Connected to 10.129.14.150.
Mode: netascii Verbose: off Tracing: off
tftp> get router-running.cfg
Received 4096 bytes in 0.1 seconds
tftp> quit

Unauthenticated: Direct file retrieval without login prompt.
