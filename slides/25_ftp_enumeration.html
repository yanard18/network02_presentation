Reconnaissance: FTP & TFTP Enumeration

Servis konfigürasyonlarını, anonymous access durumunu ve kimlik doğrulamasız dosya paylaşımlarını keşfetme.

root@htb:~# nmap -sV -sC -p 21,69 10.129.14.150 
PORT   STATE SERVICE VERSION
21/tcp open  ftp     vsftpd 3.0.3
|_ftp-anon: Anonymous FTP login allowed (FTP code 230)
| ftp-syst: 
|_  STAT: UNIX Type: L8
69/udp open  tftp    tftp-hpa 5.2
Recon Stratejisi: FTP daemon servisleri için port 21 (TCP) ve TFTP server sistemleri için port 69 (UDP) taraması yapılır.
RECON CHECKLIST Enumeration Vectors
  • Service Banners: Daemon tipi ve versiyon bilgilerini elde etme (vsftpd, ProFTPD).
  • Anonymous Login: Varsayılan anonymous:anonymous kimlik bilgilerini test etme.
  • Dizin Denetimi: LIST, PWD ve CWD komutlarıyla okuma/yazma yetkilerini kontrol etme.
  • TFTP Dosya Toplama: Hassas yedek konfigürasyonları için UDP 69 portunu sorgulama (startup-config, id_rsa).
