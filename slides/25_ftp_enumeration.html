Reconnaissance: FTP & TFTP Enumeration

Discovering service configurations, anonymous access, and unauthenticated file shares.

root@htb:~# nmap -sV -sC -p 21,69 10.129.14.150 
PORT   STATE SERVICE VERSION
21/tcp open  ftp     vsftpd 3.0.3
|_ftp-anon: Anonymous FTP login allowed (FTP code 230)
| ftp-syst: 
|_  STAT: UNIX Type: L8
69/udp open  tftp    tftp-hpa 5.2
Recon Strategy: Probe port 21 (TCP) for FTP daemons and port 69 (UDP) for TFTP servers.
RECON CHECKLIST Enumeration Vectors
  • Service Banners: Extract daemon type & version info (vsftpd, ProFTPD).
  • Anonymous Login: Test default anonymous:anonymous credentials.
  • Directory Audit: Check read/write access with LIST, PWD, and CWD commands.
  • TFTP File Harvesting: Probe UDP 69 for sensitive backup configs (startup-config, id_rsa).
