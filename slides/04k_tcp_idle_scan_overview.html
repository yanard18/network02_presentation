TCP Idle Scan (-sI)

Forged paketleri masum bir zombie host üzerinden sektiren "blind" port tarama tekniği.

BLIND SCANNING Evasion ve Spoofing
  • Sıfır Doğrudan Paket: Saldırgan, kendi IP adresinden hedefe doğrudan tek bir paket bile göndermeden hedefi tarar.
  • Zombie Host Üzerinden Sektirme: Trafik, boşta (idle) duran bir "zombie" host üzerinden sektirilir. Hedef IDS logları masum zombie host'u saldırgan olarak kaydeder.
RAW PACKETS SYN Probe Paketini Forged Oluşturma
  • TCP Payload Oluşturma: Hedef port bağlantısı talep etmek için SYN = 1 olarak ayarlar.
  • IP Header Spoofing: Destination IP = Target IP ve Source IP = Zombie IP olarak ayarlar!
