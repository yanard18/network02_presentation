Micro Segmentation: Kural Uygulama Yaklaşımları

Güvenlik sınırlarını tek bir çevre firewall'undan doğrudan iş yüklerine indiren 3 temel yöntem.

HOST LEVEL Agent-Based

İş yükü üzerine yüklenen yazılım ajanı ile izolasyon.

  • Her host ve container üzerine hafif bir yazılım agent'ı kurulur.
  • İzolasyon ve erişim kuralları doğrudan işletim sistemi / süreç seviyesinde uygulanır.
  • Ağ altyapısından bağımsız olarak yüksek hassasiyette güvenlik sağlar.
INFRASTRUCTURE Network-Based

Ağ katmanında ve sanallaştırma altyapısında denetim.

  • Denetim hypervisor virtual switch'leri, load balancer'lar veya SDN controller katmanında gerçekleşir.
  • Paketler ağ hattında ilerlerken denetlenir ve engellenir. Korunan server sistemlerine hiçbir şey kurulmaz.
CLOUD NATIVE Native Cloud Controls

Bulut sağlayıcılarının yerleşik güvenlik mekanizmaları.

  • AWS Security Groups veya Azure Network Security Groups (NSG) gibi yerleşik özellikler kullanılır.
  • İzolasyon sınırları bulut sağlayıcısının alt yapı dokusu (cloud fabric) tarafından yönetilir.
