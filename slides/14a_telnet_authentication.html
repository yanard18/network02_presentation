Telnet Authentication Architecture

How Telnet delegates user authentication to the host operating system.

PROTOCOL LIMITATION Zero Native Auth
  • No Built-in Auth: RFC 854 has no cryptographic handshake or authentication layer.
  • Post-Handshake Trigger: Authentication begins after completing TCP 3-way handshake on Port 23.
  • PTY Allocation: Receiving daemon (telnetd) initializes a Pseudo-Terminal interface.
  • OS Delegation: telnetd hands off login prompt directly to host '/bin/login'.
