FTP Bounce Attack

Abusing FTP PORT commands to proxy malicious traffic through vulnerable FTP servers.

PROTOCOL ABUSE Indirect Proxying
  • Vector: Attacker issues PORT command instructing FTP server to connect to a third-party target.
  • Impact: Bypasses internal firewalls, masks attacker IP, and enables internal port scanning.
  • Mitigation: Disable proxying in daemon config & enforce passive mode only.
Bounce Relay: Intermediate FTP server relays commands to victim host.
