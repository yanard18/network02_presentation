Legacy Remote Access: Telnet

ARPANET virtual terminal protocol providing unencrypted remote CLI shell access.

ARCHITECTURE Protocol Basics
  • Origin: Created in 1969 for text-based remote shell access.
  • Architecture: Client connects to remote daemon (telnetd).
  • Ports: TCP 23 (default) & TCP 2323 (embedded IoT).
  • Transport: Raw 8-bit ASCII stream over unencrypted TCP.
root@htb:~# telnet 10.10.11.20 23 
Trying 10.10.11.20...
Connected to target.htb.
target login: admin
Password: Password123!

admin@target:~$ id
uid=1000(admin) gid=1000(admin)

Cleartext Stream: Credentials & commands transmitted in plaintext.
