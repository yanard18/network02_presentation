Legacy Uzaktan Erişim: Telnet

Şifresiz uzaktan CLI shell erişimi sağlayan ARPANET virtual terminal protokolü.

MİMARİ Protokol Temelleri
  • Köken: 1969 yılında metin tabanlı uzaktan shell erişimi için geliştirilmiştir.
  • Mimari: Client, uzaktaki bir daemon (telnetd) yapısına bağlanır.
  • Portlar: TCP 23 (varsayılan) ve TCP 2323 (gömülü IoT).
  • İletim: Şifrelenmemiş TCP üzerinde raw 8-bit ASCII veri akışı.
root@htb:~# telnet 10.10.11.20 23 
Trying 10.10.11.20...
Connected to target.htb.
target login: admin
Password: Password123!

admin@target:~$ id
uid=1000(admin) gid=1000(admin)

Cleartext Akışı: Kimlik bilgileri ve komutlar plaintext olarak iletilir.
